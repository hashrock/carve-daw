Third-party notices for Carve DAW
==================================

This file is shown from the Carve DAW Apple menu (Third-Party Notices) and
from the About window, and it is copied into the application bundle at
Contents/Resources/THIRD_PARTY_NOTICES.txt.

Two distributions are built from the same source. The source and the GitHub
Releases disk images are under the GNU Affero General Public License, version
3 or later (see the LICENSE file and https://www.gnu.org/licenses/agpl-3.0.html).
The Mac App Store build (CMake option CARVE_APP_STORE) is not offered under
that licence. It is built under the JUCE 8 Starter licence and the Tracktion
Engine Personal licence, and it is delivered under Apple's App Store terms.
LICENSING.md in the source tree describes both, including the revenue caps.

The notices below name the components that are, or can be, linked into the
application. Versions are the ones this tree builds: tracktion_engine v3.2.0
and the JUCE 8.0.6 submodule inside it.

Not linked into the application
-------------------------------

    SoundTouch
        LGPL-2.1-or-later, copyright Olli Parviainen. Present in
        tracktion_engine at modules/tracktion_engine/3rd_party/soundtouch.
        The build sets TRACKTION_ENABLE_TIMESTRETCH_SOUNDTOUCH=0, and
        patches/tracktion-soundtouch-optional.patch keeps the engine from
        compiling its tempo detector regardless of that switch. No SoundTouch
        source is compiled into either build.
    AirWindows
        Present in tracktion_engine. TRACKTION_AIR_WINDOWS is left unset,
        because the bundled copy does not include a licence text. The effect
        is not compiled into Carve.
    Catch2 (Boost Software License 1.0) and RapidCheck (BSD)
        Fetched only when the test targets are built. They are not linked
        into Carve DAW.app.
    iconv
        On macOS the UTAU voicebank reader links the system libiconv. It is
        not bundled.
