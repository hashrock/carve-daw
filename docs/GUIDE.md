# Carve DAW 使い方ガイド

README の「機能」を、画面ごと・機能ごとに詳しく書いたもの。

## 画面

- **メイン**: 左上のロゴがファイルメニュー (Open Recent に直近 10 曲)。
  ツールバーは Orion 流に BPM /
  Pattern・Song / トランスポート / BAR / LOOP (Start・Length) / マスター。
  **Pattern** は各 Generator で最後に選んだパターンを全部同時にループ再生
  (いちばん長いパターンの長さでループし、短いものは繰り返す)、**Song** は
  プレイリストを再生。
  画面もモードに合わせて切り替わる。Pattern モードではプレイリストの場所が
  **パターンラック**になり、各行にその Generator が今鳴らしているパターンが
  ループの長さぶん (短いものは繰り返して) ノートの縮図つきで並び、再生位置が
  回る。行の頭のパターン名をクリックで別のパターンに替え、ダブルクリックで
  ピアノロールを開く。白枠の行が選択中の Generator で、MIDI 録音や Capture の
  入る先 (上部に「input -> Generator / パターン」と出る)。ラックはループが
  画面幅に収まるズームで開き、Song に戻るとプレイリストが元のズームで戻る
  プレイリストの左の行ラベルが Generator の一覧で、最下段の「+ Generator」で
  追加、右クリックでリネーム / 削除
- **Generator ウィンドウ**: 行ラベルのダブルクリックで開く (ミキサーのストリップ名の
  ダブルクリックでも)。**Inst** タブが音源のエディタ、**Pianoroll** タブがパターンの編集。
  Analog Drums とドラムキットでは、ロールの鍵盤カラムが音名でなく音色名になり
  (キック / スネア / パッドのサンプル名)、音が入っていないレーンは沈む。
  開いたときもその帯域が映る。上部のピッカーでパターンを選び、
  New / Clone / … (他 Generator へコピー、MIDI 入出力)。Inst タブは表示中の
  エディタの大きさにウィンドウが合う
- **ブラウザ**: プレイリストの左 (⌘B で表示 / 非表示)。上段がお気に入りフォルダ、
  下段がそのフォルダの中身 (サブフォルダとオーディオファイル)。`+` か Finder
  からのフォルダのドロップでお気に入りに登録、★ で今のフォルダを登録 / 解除。
  クリックで試聴 (スピーカーで切替)、ファイルはドラムキットのパッド・
  サンプラーの Inst タブ・プレイリストへドラッグ & ドロップ、ダブルクリックで
  選択中の Generator に読み込む (サンプラーなら差し替え、ドラムキットなら空き
  パッドへ、それ以外なら新しいサンプラーを作る)。お気に入りと開いていた
  フォルダはアプリの設定として残る

## 機能

- **Generator** (楽器)。内蔵音源とプラグインのパッチは `.carve` に入る
  - **Slate**: 内蔵シンセ。エンジンの 4OSC を音源に、専用のパネルをかぶせたもの。
    帯域制限ウェーブテーブル・ボイスごとのフィルタ・パラメータのスムージング・
    指数 AMP エンベロープはエンジン側の作りをそのまま使う。パネルは OSC1・OSC2 /
    FILTER / AMP / OUT の信号経路と、VOICE / LFO の 2 段。LFO は行き先 (Pitch・
    Filter・Width) を選ぶと 4OSC のモジュレーションマトリクスに書き込まれる
  - **Analog Drums**: 内蔵ドラムシンセ。ハイハットは 6 基の矩形波を帯域通過した
    往年のアナログ回路どおり、CH が OH をチョークする
  - **Gabber Kick**: ガバ／ハードコアのキックを作るキック専用音源。ピッチと音量の
    エンベロープ、Drive Stage (時間変化する EQ → 自由カーブのシェイパー) をグラフで
    編集する。Stage はいくつでも足せて、順序変更・複製・バイパスができる。ノート 36 が
    作った音程どおりに鳴り、他のノートは音程を変えて鳴らす。Export WAV で書き出せる
  - **サンプラー** / **ドラムキット** (16 パッド、GM 配列)
  - **SF2 Player**: SF2 プレイヤー (発音は TinySoundFont)。プリセットは一覧から
    選び、選ぶとその音で鳴らして聞かせる。矢印キーで順に聞き比べ、上の欄で名前を
    絞り込める。バンク 128 は GM のドラムキット。同じ .sf2 を使う Generator
    同士はサンプルを共有するので、GM 音源 1 本からピアノ・ベース・ドラムを
    別々の Generator に取っても読み込みは 1 回
  - **Singer**: UTAU 形式の音源で歌う。下の「歌わせる」を参照
  - **Break Slicer**: ドラムループ (アーメンなど) をスライスして叩く。下の
    「ブレイクを刻む」を参照
  - **VST3・AU** (プラグイン自身のプリセットも Presets メニューから選べる) /
    **オーディオトラック**
  - サンプラー・SF2 Player・Singer・Break Slicer は「+ Generator」で選ぶとすぐ空のまま作られ、
    その Inst タブが開く (ファイル選択で待たされない)。空の Inst タブには Load
    ボタンと、その種類で最近使ったファイル (Singer は音源フォルダ) の一覧が出て、
    一覧はクリック 1 回で読み込む。仮の名前 ("Sampler 2" など) のままなら、
    最初に読み込んだファイル (Singer は音源の名前) が Generator の名前になる。
    サンプルや .sf2、音源フォルダは相対パスでも覚え、見つからなければ Missing
    Media に出る
- **歌わせる (Singer)**
  - 音源のフォルダを読み込む。単独音・連続音・エクストラなど、フォルダ以下の
    oto.ini は全部まとめて読み、Shift_JIS と UTF-8 のどちらでもよい
  - 歌詞はピアノロールでノートをダブルクリックして打ち、Tab / Shift+Tab で前後の
    ノートへ移る。かなでもローマ字でもよく、空のノートは「あ」で歌う
  - 前のノートにつながっていれば連続音 (「a か」など)、句の頭なら「- か」、
    なければ単独音を選び、prefix.map の音域別の録音も使う。録音が見つからず
    無音になるノートは、ピアノロールで赤い斜線と赤枠になる (打っている途中の
    歌詞も赤くなる)。Inst タブにはパターン中の無音のノートの数が出る
  - 合成は WORLD (OpenUtau の WORLDLINE と同系統) でノートごとに裏で行い、
    子音はノートの頭より先行発声のぶん先に鳴る。つながったノートの間は自動の
    ポルタメント。打ち込んだ直後はまだ合成中で鳴らないことがある (Inst タブに
    進み具合が出る)。MIDI キーボードやプレビューは「あ」の録音を音程だけ変えて
    鳴らす
  - Inst タブの 4 つのつまみで声質を変えられる: **Gender** (声道の長さ。+ で
    太く大人っぽく、- で細く若く。音程は変わらない) / **Breath** (息の量、50 が
    録音どおり) / **Brightness** (音色の明るさ) / **Modulation** (録音の音程の
    揺れを残す量、0 で真っ直ぐ)。離したときに確定し、Undo でき、そのパートは
    全部合成し直しになる
- **ブレイクを刻む (Break Slicer)**
  - ループを読み込むと 16 等分に切られ、スライス 1 が C1 (ノート 36)、
    スライス 2 がその半音上…と並ぶ。同時に「録音どおりに並べたパターン」が
    でき、読み込んだ直後から元のループがテンポに合わせて鳴る。そこから
    ピアノロールでノートを並べ替えれば刻める
  - 鳴るのは常に 1 スライスだけで、次のノートが前のスライスを止める (チョーク)。
    ノートを離すとそこで止まり、次のカットより先へは鳴らない。短いノートを
    連打すればスタッターになる
  - 小節数はファイル名のテンポ (`amen_175.wav` の 175 など) と長さから推定し、
    名前に無ければ 140 BPM に近くなる小節数を選ぶ。Inst タブの Bars で直せる
  - カットは Inst タブの波形で編集する: 4 / 8 / 16 / 32 等分、**Detect** (打点で
    切る。右のスライダーで感度)、ダブルクリックで追加、ドラッグで移動 (近くの
    ゼロクロスに吸着、Alt で吸着なし)、右クリックで削除。スライスをクリックすると
    試聴できる。どれも 1 回の操作が 1 回の Undo。波形は ⌘ (Ctrl) + スクロールか
    ピンチでポインタの位置を中心にズームし、スクロールか下のスクロールバーで
    左右に動かす。- / + / Fit ボタンでも同じ
  - **奏法**: ピアノロールの上に帯が出て、左から **Play** (奏法) / **Roll** /
    **Tune** の 3 つに分かれている。奏法のボタンはノートに付く印と同じ絵で、
    名前はポインタを乗せると出る。Buzz の音名と Ramp は Buzz を選んだときだけ、
    ロールの強弱 (＝ ＜ ＞) はロールを入れたときだけ出る。右端に何に効くか
    (「3 notes」= 選択中のノート、「next note」= 何も選んでいなければ次に描く
    ノート) が出て、**Reset** で普通のノートに戻す。Tune はダブルクリックで 0
    - **Reverse**: スライスを後ろから逆再生
    - **Tape Stop**: ノートの長さをかけて、電源の切れたテープのように減速して止まる
      (次のカットを越えてループの先まで流れる)
    - **Fade In** / **Fade Out**: ノートの長さをかけて音量を上げる / 下げる
    - **Buzz**: スライスの頭を音程になる速さで打ち直す (ピッチド・スタッター)。
      隣の欄で音名を選ぶ (C0〜C6、テンポに関係なくその音程で鳴る)。**Ramp** を
      入れると 1/16 のロールから始まって、ノートの長さをかけてその音程まで加速する
    - **Roll**: ノートの間、1/8〜1/64 (三連も) でスライスを打ち直す (リトリガー)。
      奏法と組み合わせられ、Roll + Reverse で逆再生の連打になる。隣の欄で
      **Cresc.** (ほぼ無音からノートのベロシティまで上がる) / **Decresc.**
      (下がる) を選べる
    - **Tune**: そのノートだけスライスの音程を -12〜+12 半音変える。サンプラーと
      同じく速さも変わる (上げると短く、下げると長く鳴る)。奏法と組み合わせられる
    - ノートには奏法の印 (逆再生の三角、テープストップの曲線、フェードの斜線、
      バズのノコギリ波と音名)、右端に Tune の値、
      ロールの打ち直し位置の縦線 (強弱に合わせた高さ) が出る。コピー・複製・パターンの Clone でも引き継ぐ
  - カットを足すと後ろのスライスの番号が 1 つずつずれるが、既存のノートも一緒に
    ずれるので、どのノートも前と同じ音を鳴らし続ける (割ったスライスのノートは
    前半に残る)。消すときは前のスライスが伸びて、消したスライスのノートを引き取る
  - 録音どおりのパターンは、手を加えていないうちはカットの編集に追従して作り直される。
    一度ノートを動かしたパターンはユーザーのものとして触らない
  - **Repitch** を入れると、ループ全体を曲のテンポに合わせて速く / 遅く再生する
    (音程も変わる、昔のサンプラーの鳴り方)。切ったままだと各スライスは元の速さで
    鳴り、テンポで変わるのは鳴り始めの位置だけ。Repitch が追うのは曲頭のテンポ
- **ピアノロール**: Shift 押下中は一時的に選択ツール、⌘ ドラッグで複製
  (ドラッグの途中からでも)、Ctrl 押下中は Snap を無視、選択ノート上の
  右クリックで選択を削除、ペーストはポインタ位置へ、クオンタイズ / スウィング
  (50% がストレート、66% で三連のノリ)
- **プレイリスト**: 配置ごとの長さ (ループ / 切り詰め) と transpose、途中での
  テンポ・拍子変更、オーディオファイルのドラッグ & ドロップ。クリップの
  パターン名をクリックすると差し替えのドロップダウンで、New / Clone から
  その場で新しいパターンも作れる (今と同じ長さなので配置は動かない)。
  ここで選んだパターンはその行の選択になるので、次にペイントで置くクリップも
  それになる
- **ミキサー**: ストリップ名のダブルクリックで Generator ウィンドウ。エフェクトの
  ウィンドウは基本パラメータの一覧だが、絵で見たほうが早いものには上部に図が付く
  (4-Band EQ は応答カーブとバンドごとのハンドル: ドラッグで周波数とゲイン、
  ホイールで Q、ダブルクリックでフラット。Overtop は 3 バンドの入力レベルと、
  ドラッグできる threshold の線)。新しい曲の
  マスターには音割れ防止の **Limiter** が最初から挿さっている (先読み式の
  ブリックウォール。普通のインサートなので、動かすことも外すこともできる)。
  **パン**は等パワー則で、センターでは音量が変わらず、振り切ると近い側が
  +3dB・反対側が無音になる (左右合計のパワーはどこでも同じなので、パンを
  動かしても音量感が変わらない)。この方式より前に作った曲は、作られたときの
  リニア則 (振り切ると近い側 +6dB) のまま鳴る。
  **グループバス**: ストリップの「group」ボタンで New Group を選ぶとバスが
  できて、そのトラックはマスターではなくバスを通る (Live の Group Tracks と
  同じ考え方)。バスにはフェーダー・パン・ミュート・ソロ・エフェクトがあり、
  バスをソロにするとその中身だけが鳴る。バス内のトラックをソロにしても
  バス自体は黙らない。ステム書き出しでは、グループは 1 本のステムになる
  (バスは自分に入ってくるトラックを全部引き込むので、メンバー 1 本だけを
  取り出すことはできない)。
  センド / リターンバス。コンプは別 Generator を**サイドチェイン**元に
  できる。コンプのウィンドウにはリダクション量のメーターが出る。エフェクトは
  tracktion 内蔵 + 自前の **Overtop** (3 バンドのアップワード + ダウンワード
  コンプ。LR4 クロスオーバー、バンドごとのゲイン、Depth で並列ミックス) /
  Distortion / Saturation / **Bitcrusher** (ビット深度とサンプルレートを
  連続的に落とす。オートメーションで滑らかにスイープできる) / **Delay** (テンポ同期の音価、
  量で効くピンポン、L に対する R のオフセット、フィードバック内の低域/高域カット、
  ディレイタイムの LFO、幅) + VST3 / AU
- **マスタリングモード** (⇧⌘M / ツールバーの Master ボタン / ミキサーの
  MASTERING 見出し): ミキサーのマスターストリップには、マスターのエフェクトの
  下にもう 1 本 **マスタリングチェーン**がある。重いリミッターやマキシマイザー、
  仕上げの EQ はここに挿す。マスタリングモードが OFF の間 (起動時はこちら)
  チェーンはバイパスされ、再生グラフから外れるので CPU もレイテンシ
  (リミッターの先読みなど) も食わない。ON にすると聴こえる。チェーンの
  エフェクトは OFF のままでも足したり調整したりできる (薄く表示される)。
  モードは曲には保存されない聴き方の切り替えで、チェーンの中身は曲に保存される。
  信号はマスターのエフェクト → マスタリングチェーン → マスターフェーダーの順
  (フェーダーは常に最後)。**ミックスダウンの書き出しはモードに関係なく
  チェーンを通す** — 書き出し画面の「Through the mastering chain」を外すと
  通さない (外部でマスタリングしてもらう 2mix 用)。ステムにはもともとマスターの
  エフェクトが入らないので、マスタリングチェーンも入らない。CLI
  (`carve-render`) も既定で通し、`--no-mastering` で外せる
- **オートメーション**: パラメータカーブと LFO モディファイア。どちらも拍基準で
  テンポ変更に追従
- **MIDI 入力と録音**: 接続された MIDI キーボードは選択中の Generator を鳴らす。
  録音ボタン (⌘R) を押すと再生が始まり、弾いた音がそのとき鳴っているパターンに
  重ね書きされる — Pattern モードなら選択中のパターンにループで、Song モードなら
  プレイリストで再生ヘッドの下にあるクリップのパターンに (クリップの transpose は
  差し引かれる)。録音した 1 パスは undo 1 回で消える
- **Capture (後から拾う)**: 録音ボタンを押していなくても、弾いたものは全部
  覚えている。⇧⌘R (トランスポートの Capture ボタン) で、直前のフレーズ (2 小節
  以上の無音で区切った最後のひとまとまり) が選択中の Generator の新しい
  パターン「Capture1…」になり、その場で選択される — Pattern モードならそのまま
  ループし始めるので、重ねて弾くか録音すればよい。再生中に弾いたものは曲の
  小節線に対する位置を保ち、止まっているときに弾いたものは最初の音が頭になる。
  長さは全部の音の頭が入るだけの小節数
- **PC キーボードで弾く**: ⌘K (トランスポートのキーボードボタン) で、MIDI
  キーボードがなくても弾ける。A〜; が白鍵、W/E/T/Y/U/O/P が黒鍵、Z/X で
  オクターブ。A はふつう C4、ドラムの Generator ではキック (C2)。入っている間は
  それらの文字キーは音符なので、ピアノロールの D / E などのツール切り替えは
  効かない (修飾キー付きのショートカットとテキスト入力はそのまま)。録音も
  Capture も MIDI キーボードと同じに効く
- **書き出し** (⌘E): ミックスダウンかステム (Generator ごとに 1 ファイル) を、
  WAV (16/24/32 bit) か Ogg Vorbis (64〜500 kbps) で。Pattern モードのまま
  開いても、書き出すのはソング。範囲は曲全体 / LOOP の範囲 / **ゲームループ**。ゲームループは曲頭から LOOP の終わりまでを書き出して
  そこで切り (テールは付けない)、LOOP の頭の位置を Ogg の `LOOPSTART` と
  `LOOPLENGTH` (どちらもサンプル数) に書き込む — RPG ツクール MV/MZ など、
  このコメントでイントロ付きループを再生するゲームエンジン向け。WAV には
  書き込まれないが、値は書き出し画面に出る。LOOP の終わりをまたいで鳴る音の
  余韻はループの頭には回り込まず、そこで切れる
- **設定画面** (⌘, / View メニュー / アップルメニュー): オーディオ出力デバイス・
  サンプルレート・バッファサイズと、使う MIDI 入力デバイスの選択。オーディオ
  入力は出てこない (開かない理由は [DEVELOPMENT.md](DEVELOPMENT.md#オーディオ入力を開かない理由-midi-入力は開く))。設定はエンジン側にそのまま
  保存され、適用ボタンの類はない
- **付属コンテンツ**: サンプル曲 3 曲 (File > Open Sample Song / ロゴメニュー) と
  ファクトリードラムキット 9 音。曲は内蔵音源だけで組んであるので外部ファイルを
  参照しない。キットは `content/Drums` に実ファイルとして入り (アプリバンドルの
  `Resources/Content` にコピーされる)、初回起動時にサンプルブラウザの
  お気に入りとして開かれる。音は `scripts/generate-drums.py` で合成したもので、
  ライセンスの要らない自前の素材
